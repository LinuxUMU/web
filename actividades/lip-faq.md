# PREGUNTAS FRECUENTES LINUX INSTALL PARTY

## ¿Por qué necesito Linux?

Para algunas asignaturas a lo largo de primero necesitarás usar algunas herramientas que no están disponibles en Windows, y tener un entorno Linux es indispensable para **preparar prácticas y exámenes** en casa. Pero además, a lo largo de tu carrera informática, es una realidad que te lo van a pedir. si quieres aprender sistemas, redes, hardware o embebidos **TODO** es Linux.

## ¿Por qué no usar alternativas/versiones para Windows del software que usamos en clase?

Además de que en algunos casos será necesario utilizar una terminal Linux _per se_, acostumbrarse a Linux todo lo posible desde el principio, incluso para tareas que podríamos hacer en entornos Windows, **te facilitará el trabajo** no solo durante este curso, sino también para los posteriores.

## "Con Windows me apaño, ya aprenderé a usar Linux cuando me haga falta".

Esto puede ser un error si nunca terminamos de acostumbrarnos a usar Linux, ya que si llegamos a una prueba sin habernos enfrentado a las típicas configuraciones e interfaces de Linux previamente, podemos tener fuertes fricciones que nos **dificulten gravemente los exámenes**.

## ¿Por qué no es más fácil tener una máquina virtual y ya?

Aunque una máquina virtual ofrece un entorno usable para salir del paso, tiene **varias fricciones** a la hora de trabajar en el día a día, como un aumento considerable en el consumo de batería y RAM, latencias molestas y fallos frecuentes causados por el software o nosotros mismos, entre otras.

## ¡Pero yo quiero seguir teniendo Windows!

¡No pasa nada! Las instalaciones de Windows son compatibles con soluciones "Dual Boot" que nos permiten decidir durante el arranque de nuestro sistema si queremos usar Windows o Linux, pudiendo **cambiar de un sistema operativo a otro** en pocos segundos.

## ¿Y si tengo un Mac?

Aunque Dual Boot no suele estar aconsejado en hardware Apple, el software de máquinas virtuales para macOS suele ser bastante amigable, por lo que usar máquinas virtuales en estos casos suele ser la mejor opción. (**¡También podemos ayudarte en esto!**)

## Me han dicho que Linux es para usuarios expertos. ¡Yo aún no sé nada de informática!

Tranquilo. Que desde Linux podamos usar herramientas avanzadas no significa que el día a día sea difícil ni mucho menos. Los escritorios más populares a día de hoy ofrecen interfaces **fáciles de usar para cualquiera**, y podremos explorar archivos o usar el navegador de internet con total normalidad igual que haríamos en entornos Windows.

## Ok, ya entiendo lo importante que es tener mi propia instalación de Linux. ¿Cuándo y dónde es?

Este **viernes 25 de septiembre**, en el **Aula 0.01**, durante **todo el día**, mañana y tarde, para que puedas ir cuando no tengas clase.

## ¿Qué necesito?

Basta con traer **tu ordenador** con mínimo **64GB de espacio libre**, su **cargador** y un **pendrive** de **8GB** cuyo contenido no te importe perder (si no tienes, se te puede prestar uno o utilizaremos otros métodos de instalación, pero traer tu propia unidad pendrive sigue siendo **muy recomendable**). Es recomendable también hacer una copia de seguridad de aquellos archivos importantes que no queramos perder de nuestra instalación de Windows, ya que aunque la instalación de Linux es un proceso **0% invasivo**, un error nos podría provocar perdidas de información.
